# Security policy

Do not report security vulnerabilities in a public issue. Contact the maintainer privately through the contact method listed on the maintainer's GitHub profile and include a concise description, affected version, and reproduction steps without real meeting data.

Meeting Notes does not require cloud access for recording or transcription. Treat any change that transmits audio, transcripts, meeting metadata, calendar data, or local paths as security-sensitive and require explicit user consent and documentation before release.
