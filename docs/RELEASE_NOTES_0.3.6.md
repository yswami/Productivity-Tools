# Meeting Notes 0.3.6

- Detects visible Google Meet and Microsoft Teams call windows independently of the browser.
- Adds direct call-tab detection for Brave, Chrome, Edge, and Safari.
- Prioritizes browser detection before the Accessibility-dependent native Teams check.
- Shows an actionable macOS permission message when automatic detection is blocked.
- Lets users rename meetings from the notes dialog and refreshes an existing calendar file with the new name.
