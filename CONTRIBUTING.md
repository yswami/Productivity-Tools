# Contributing

Thank you for testing Meeting Notes.

Use GitHub Issues for reproducible defects and feature requests. Include the application version, operating system version, meeting platform, expected behavior, and observed behavior.

Do not post meeting audio, transcripts, participant names, company-confidential information, credentials, or private file paths. Replace sensitive values in logs before attaching them.

Code changes should keep transcription offline, preserve explicit recording visibility, and include focused tests for changed behavior. Run `npm run test:unit` and `npm run build` before opening a pull request.
